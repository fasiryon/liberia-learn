# LiberiaLearn model-neutral repository context

`AGENTS.md` is the repository entry point. It links the single source of truth
for universal rules and the progressive-disclosure routes. This file adds no
second reading order and no model-specific itinerary.

Use current-state and rollout documents only for national rollout or sprint
planning. Use the relevant operational, security, curriculum, or AI contract
only when the task enters that domain. Verify live claims independently before
reporting them; historical notes are evidence, not authorization.

Production feature flags, provider funding, and release checks belong to the
deployment route, not ordinary local tasks.
