# GENERATED — Automated Output

All files in this folder are written by automated workflows.
Do NOT edit them directly — re-run the workflow to regenerate.

## Subfolders

| Folder | Written by | Frequency |
|---|---|---|
| `briefings/` | Workflows 01, 02, 06 | Daily / On-demand |
| `reports/` | Workflows 04, 05 | Sprint close / Weekly |
| `drafts/` | Draft workflow (from QUEUE/) | On-demand |
| `communications/` | MOE brief workflow | On-demand |

## Naming Convention
All files: `YYYY-MM-DD-[type]-[description].md`

## Retention
Keep the last 30 days of daily pulses.
Keep all sprint reviews and MOE briefs indefinitely.
Archive older files to `05-REVIEWS/` quarterly.
