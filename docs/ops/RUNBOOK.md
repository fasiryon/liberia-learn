# Ops Runbook (V1)

## Daily Checks
- error rates (500/401/429)
- latency trends
- SMS delivery rates + opt-out anomalies
- offline sync failures and conflicts
- AI request failure rate and slowdowns

## Weekly Discipline
- 1 stability freeze window per week
- review telemetry dashboards
- review incident cards
- prune/resolve feature flags

## Recovery Tools
- feature flags / kill switches
- throttles and quiet hours policies
- degraded mode
