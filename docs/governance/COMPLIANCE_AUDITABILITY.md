# Compliance & Auditability

## Audit Logging
Every critical action must log:
- tenant ID
- user ID
- role
- timestamp
- action type
- target entity ID(s)
- result (success/failure)

## Messaging Compliance
- opt-in/out tracked
- quiet hours enforced
- per-guardian throttles
- school-level policies

## AI Auditability
- AI prompt/template version
- input references
- output artifact version
- teacher edits/overrides
