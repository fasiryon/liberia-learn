# Data Governance (V1)

## Ownership
Schools own their data. LiberiaLearn is the processing platform.

## Retention
Define default retention period by category:
- student records
- audit logs
- message logs
- AI artifacts
(Exact durations can be configured later; V1 must support policy enforcement.)

## Export
Schools must be able to export:
- student profiles
- submissions and grades
- attendance (if applicable)
- audit summaries
- curriculum/lesson artifacts (where permitted)

## Deletion
Support:
- student deletion (policy-bound)
- guardian phone removal
- school offboarding deletion workflow

## Offboarding Protocol
When a school leaves:
- export final archive
- disable new access
- follow deletion/retention policy
- produce offboarding report

## Audits
Provide:
- “who accessed what” reports
- admin actions summary
- messaging activity summary
