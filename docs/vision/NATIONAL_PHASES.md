# LiberiaLearn — National Phases (V1)

LiberiaLearn is **not a demo**. It is national infrastructure.

## PHASE 1 — Core Stabilization & Backbone
Auth, dashboards, multi-tenancy isolation, offline sync, guardian SMS, metrics, audit logs, health checks, API validation, Prisma/Supabase stabilization, test foundation.

Additions required in Phase 1:
- Abuse & role protection: permission ceilings, rate limits, messaging throttles, tenant emergency disable switches, admin override audit trails.

## PHASE 2 — AI Curriculum & Instruction Engine
AI factory integration, curriculum synthesis (MOE-aligned + WAEC-capable + global benchmarking), lesson generation, teacher review workflows, mastery tracking, analytics.

Additions required in Phase 2:
- AI transparency: explanations, confidence, override, acceptance/rejection telemetry, version history.

## PHASE 2.5 — National Adoption & Digital Literacy Infrastructure
Built for low computer literacy environments:
1) Guided Interaction Layer (operational guidance)
2) AI Teacher Co-Pilot ("Ask LiberiaLearn")
3) Training Center (Levels 1–3)
4) Progressive Disclosure UI (Basic/Standard/Advanced density; single codebase)
5) School Champion model
Plus: accessibility, large font, low-bandwidth mode, offline UX clarity.

## PHASE 3 — National Governance, Compliance & Reliability
MOE dashboards, compliance, school configuration at scale, localization, observability, resilience, scaling.

Additions required in Phase 3:
- Data Governance & Ownership layer: retention, export, deletion, offboarding, encryption, access audits.
- Load simulation & stress testing framework: students/teachers/SMS/offline conflicts/AI burst testing.

## PHASE 4 — National Intelligence Layer
Adaptive learning, predictive risk/dropout analytics, national dashboards, regional comparisons, reporting API, strategic insights.

All Phase 4 features must be:
- feature-flagged
- measurable
- reversible
- non-disruptive to Phase 1 core

## Cross-Phase Tracks (Permanent)
### Track A — Digital Literacy Enablement
Guidance + training + co-pilot + progressive UI + accessibility

### Track B — Self-Healing Ops / Fix-It AI Agent
Incident detection + diagnosis + safe mitigations + PR drafting (human-approved)
No autonomous prod deploys, no autonomous DB migrations, no autonomous auth/tenancy edits.
