# Low-Literacy UX Standard (V1)

## Principles
- Big buttons, clear icons, minimal clutter
- Progressive disclosure: Basic -> Standard -> Advanced
- Help is always available on-screen
- Offline state is obvious

## Required UX Features
- guided interaction flows
- re-openable help
- training center access from every dashboard
- large-font toggle
- low-bandwidth mode (reduce heavy UI payloads)

## Success Metrics
- onboarding completion rate
- help invocation rate
- workflow completion rate (create lesson, assign, grade, message)
