## Build decimal place value

### places: intro

We will explain how the value of a digit changes with its place, including places smaller than one.



### places: model

In 32.45, 3 represents thirty, 2 represents two, 4 represents four tenths and 5 represents five hundredths. Each place to the right has one tenth the value of the previous place.



### places: guided

For 24.36, label tens, ones, tenths and hundredths. Then describe the value represented by 3.

Explain the value of 3 in 24.36 using the place labels.

### places: independent

Work alone. Write the number as a sum of its place values and explain what each digit represents.

Write 41.27 as a sum of place values and explain the value of 2.

### places: reflect

Describe a mistake you can now avoid. This reflection is practice and does not establish mastery.

## Compare decimals with equal units

### compare: intro

We will compare decimals and justify which has greater value without counting digits.



### compare: model

Compare 0.6 and 0.48. Six tenths is sixty hundredths. Sixty hundredths is greater than forty-eight hundredths, so 0.6 is greater.



### compare: guided

Rewrite 0.7 as hundredths. Now compare it with 0.65. Explain the common unit you chose.

Compare 0.7 and 0.65 using hundredths.

### compare: misconception

Counting decimal digits does not compare their value. For 0.5 and 0.42, think fifty hundredths and forty-two hundredths. Adding a trailing zero changes notation but not quantity.



### compare: independent

Work alone without a place chart, tutor or worked example. Explain the units used in your comparison.

Which is greater, 0.8 or 0.76? Justify using equal units.

### compare: reflect

Describe a mistake you can now avoid. This reflection is practice and does not establish mastery.

What will you check when comparing decimal quantities?

## Independent decimal production

1. Write 53.24 as a sum of place values. Explain what the digit 2 represents.
2. Compare 0.4 and 0.37. Explain using the same fractional unit.
3. Check your explanation without using a worked example. Record any help you used.

## Practise decimal explanations

1. Write 26.53 as tens, ones, tenths and hundredths.
2. Compare 0.3 with 0.28 and justify your decision.
3. Write a pair of decimals where the longer written decimal is smaller. Ask someone to listen to your reasoning without giving the answer.

## Place chart and practice sheet

### Prerequisite fallback

Draw columns labelled tens and ones. Put 4 in tens and 2 in ones. Explain how 42 differs from 24. If unsure, make four groups of ten marks and two single marks. Repeat with 31, then remove the drawing.

### Faded decimal support

Add tenths and hundredths columns. Place 3.25 in the chart. State each digit's value. Cover the labels and explain 7.46. Finally work without the chart: compare 0.2 and 0.19 using equal place units.

## Teacher guide

### Before instruction

Administer the quiz as a diagnostic without feedback. Route tens/ones errors to the worksheet. Keep this separate from the end-of-unit measure. All numerical contexts in this package are invented classroom examples, not reported local measurements or prices.

### Differentiation and independence

Offer oral directions, large print and a place chart during instruction. Fade the chart before the independent stage. A scribe may transcribe without supplying steps. Record tutoring, hints and collaboration as assistance. Do not count assisted work as independent evidence.

### Assessment and follow-up

## Paper decimal strips

1. Draw two equal-length strips divided into ten equal sections. Mark quantities 0.4 and 0.35, subdividing sections into hundredths when needed.
2. Label the units in text; do not rely on colour. Explain which marked length is greater.
3. If drawing is difficult, dictate a table of tenths and hundredths instead. Record a written justification. This is practice, not a certified lab.

## Create a decimal misconception guide

1. Create a one-page guide showing two invented decimal comparisons where digit count gives the wrong answer.
2. For each comparison, show equal-unit reasoning. Include an original place-value diagram or a text table.
3. Exchange guides for comments, then submit your own revision with the help you received recorded. Practice feedback does not establish independent mastery.

## Text alternatives

### Place chart in reading order

Column one: tens. Column two: ones. Column three: tenths. Column four: hundredths. Read each digit with its column label. A blank place represents zero units of that size.

### Practical alternative

Instead of drawing shaded strips, make two text rows. Row one: four tenths equals forty hundredths. Row two: thirty-five hundredths. Compare their quantities verbally, then write your reason. The response can be typed, dictated or handwritten.

## Optional base investigation

### Non-gating extension

Imagine a counting system in which each place to the left is worth five times its neighbour. Invent notation for six objects and eleven objects, and explain your rules. Compare the grouping with our decimal system. This is a proposed LiberiaLearn extension, optional, and never required for core progression.
