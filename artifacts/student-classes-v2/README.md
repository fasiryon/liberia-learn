# Student My Classes / Class Schedule browser evidence

Generated by `node e2e/product-design-v2/run.mjs` (the CI "Validate Student Today V2 browser
fixtures" step), specifically `e2e/product-design-v2/validate-classes.mjs`.

- Widths: 320, 360, 390, 768, 1280, 1366, 1440, 1920 for My classes, class detail, schedule
  (Today) and schedule (Week); no-timetable states at 390 and 1366.
- Asserted per capture: no horizontal overflow, five primary destinations with the correct one
  active, only `/student/...` links, no wrapped action buttons. Axe WCAG 2.2 AA: no serious or
  critical issues.
- Governed current-learning task first on Today and Learn for Grade 2 and Grade 6 at every width.
- Learn My classes: 401/403 on Refresh clears class rows; 503 keeps them as last-loaded history.

These are **production components with explicit fixture models** (`classFixtures.ts`) and mocked
authorized APIs, not authenticated captures against a database. Enrollment, tenant, teacher
identity and content authorization are certified by `__tests__/student/classes-read-model.test.ts`
and `__tests__/student-read-models.test.ts`.
