## Browser evidence

These are actual production components mounted together in one browser tree with synthetic identity, curriculum and API responses. The textbook hub is rendered from the actual server route by its existing mocked-boundary test; the reader uses the authorized-reading presentation with synthetic content, explicitly named in its title. These are not live school sessions, published curriculum or proof of production authorization. Protected-route and release/preview boundaries are covered by server/unit regressions. No production design-preview flag was enabled.

[Main flow results](browser-results.json) cover Today → Learn → Lesson Read/Slides → contextual Tutor → Today; Today → Help → Learn; Learn → Textbooks → Reader; Labs → Progress → Today at 390, 768, 1440 and 1920px.
