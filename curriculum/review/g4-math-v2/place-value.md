### Every digit has a place (`places`)

Learner action: Read and say the place names in order.

From the right, the places are **ones, tens, hundreds, thousands, ten thousands** and **hundred thousands**.

The place tells the value of a digit. In 47,305 the 4 is in the ten thousands place, so it is worth 40,000. The 0 is in the tens place: there are no tens, but the 0 must stay so the 3 keeps its hundreds place.

- Each place is worth ten times the place to its right.
- A 0 holds an empty place.

- Accessibility: Places from the right: ones, tens, hundreds, thousands, ten thousands, hundred thousands. In 47,305 the 4 is worth 40,000 and the 0 holds the empty tens place. · keyboard: Read the text, then Continue.
- Offline (FULL_OFFLINE): Text only.

### Build 47,305 one place at a time (`build-47305`)

Learner action: Open each step to build the number and its expanded form.

Open each step. Watch how each digit's value adds up to the whole number.

1. **4 in the ten thousands place** — 4 ten thousands = 40,000.
2. **7 in the thousands place** — 7 thousands = 7,000.
3. **3 in the hundreds place** — 3 hundreds = 300.
4. **0 in the tens place** — No tens. The 0 holds the place.
5. **5 in the ones place** — 5 ones = 5. Expanded form: 40,000 + 7,000 + 300 + 5 = 47,305, read forty-seven thousand, three hundred five.

- Hints: Start from the left: the biggest place first.
- Accessibility: 47,305 is 4 ten thousands (40,000), 7 thousands (7,000), 3 hundreds (300), 0 tens and 5 ones: 40,000 + 7,000 + 300 + 5. · keyboard: Each step is a button; press Enter or Space to open it in order.
- Offline (FULL_OFFLINE): Text steps work offline.

## Misconceptions

- `drops-zero` (obj1): Leaves out the zero in an empty place, writing 8,304 for eighty thousand, three hundred four. → Build the number in the chart: an empty column still needs a 0 so the other digits stay in their places.
- `digit-not-value` (obj1): Gives the digit instead of its value, saying the 4 in 47,305 is worth 4. → Ask which place the digit sits in, then read the value of that place: 4 ten thousands is 40,000.
