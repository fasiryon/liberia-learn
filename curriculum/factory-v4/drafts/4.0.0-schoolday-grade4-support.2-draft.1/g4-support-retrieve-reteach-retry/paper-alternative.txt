Guided reteach cards: choose a card with your teacher. Cover these cards during independent work.

P1 / Card 1. A mistake to check: The digits of a factor are multiplied as single units and their products are added. Better idea: Name the full place values before multiplying: 2 hundreds is 200, not 2. Reconnect: Represent 312 as 300, 10 and 2. Multiply each full value by 3 before combining.

P1 / Card 2. A mistake to check: Tens or hundreds formed by a partial product are discarded when writing the final digits. Better idea: Keep the value of every partial product and regroup it into the correct place rather than deleting it. Reconnect: Trade ten ones for one ten without throwing away value. Show how 4 times 4 ones becomes one ten and six ones.

P2 / Card 1. A mistake to check: The swallowed food route is drawn through the liver or pancreas instead of distinguishing the juices they supply. Better idea: Keep the continuous food route separate from the liver and pancreas, which supply digestive juices. Reconnect: Use one arrow for swallowed food and different arrows for digestive juices. Place liver and pancreas beside the food route.

P2 / Card 2. A mistake to check: The stomach is treated as the place where all nutrients enter the body. Better idea: Most digested nutrients are absorbed through the small-intestine wall. Reconnect: Compare the stomach with the small intestine. Locate where most digested nutrients enter the body.

P2 / Card 3. A mistake to check: Nutrients that cross the wall are treated as disappearing from the model total. Better idea: Keep transferred tokens visible in the body region. Count both regions to conserve the total. Reconnect: Move paper nutrient tokens into a body region while keeping every token visible. Transferred tokens still exist.

P2 / Card 4. A mistake to check: The starting count is reported as still inside after tokens have crossed the wall. Better idea: The starting count describes both regions together. Subtract transferred tokens to find what remains inside. Reconnect: Label the starting total before moving tokens. Label the tokens still in the first region separately.

P2 / Card 5. A mistake to check: The number transferred during a round is confused with the number remaining inside. Better idea: Transferred and remaining name different groups. Track the inside count after every transfer. Reconnect: Keep transferred and remaining tokens in two labelled groups. Point to the group named by each question.

P3 / Card 1. A mistake to check: A plausible prediction is reported as something the story has already established. Better idea: Name the detail that makes the idea plausible, use might or may, and change the prediction if later evidence conflicts. Reconnect: Mark an early clue, your prediction and a later detail in the accepted reading text. Treat the prediction as a possibility.

P3 / Card 2. A mistake to check: A summary lists incidental details or invents an outcome instead of connecting the central problem, response and result. Better idea: Keep the problem, the action taken and the result supported by the story; remove details that do not explain that connection. Reconnect: Choose details that explain the main problem, response and result. Put minor details aside.

P4 / Card 1. A mistake to check: Every inland location is assumed to be high or mountainous. Better idea: Inland means away from the coast. A broad terrain description does not determine every local elevation. Reconnect: Separate coastal or inland labels from evidence about elevation or a particular route. Use the accepted records.

P4 / Card 2. A mistake to check: One observation or place description is treated as evidence about all communities. Better idea: Name the place and observation, limit the conclusion to that evidence and seek additional observations. Reconnect: Compare what the two club records actually describe. One record does not describe every place.

P4 / Card 3. A mistake to check: Coastal or inland is treated as enough evidence to select a safe site. Better idea: Compare the actual site, path and local observations. A region label alone does not establish safety. Reconnect: Match each room or route claim to its actual observation. A place name does not establish safety.

P4 / Card 4. A mistake to check: General coast-to-inland landform descriptions are treated as exact county boundaries. Better idea: Use an administrative map for county boundaries. A physical sketch does not establish those lines. Reconnect: Use separate labels for a physical region and an administrative county. They answer different kinds of questions.

P4 / Card 5. A mistake to check: Evidence about a dry room or a clear path is treated as proving the other requirement too. Better idea: Check each requirement separately. Room and route observations answer different questions. Reconnect: Make separate columns for room conditions and route access. Check each need with relevant evidence.

P5 / Card 1. A mistake to check: The variable's name is changed whenever its number changes. Better idea: Keep the name score fixed and replace the number stored beneath it. Reconnect: Keep the score name card fixed and replace only the number card when its value changes.

P5 / Card 2. A mistake to check: Set score to a number is treated as adding that number. Better idea: Set replaces the current value. Add uses the current value to calculate the next one. Reconnect: Compare set to 2 with add 2 from the same starting score of 4. Set replaces; add uses the previous value.

P5 / Card 3. A mistake to check: Initialization is repeated before every event, discarding the accumulated score. Better idea: Initialize at new-game start and retain the updated value between events. Reconnect: Initialize at the start of a new game. Keep the updated value between hits unless a reset event occurs.

P5 / Card 4. A mistake to check: A set instruction is ignored and the previous value is retained. Better idea: Follow every instruction in order. Set replaces the old value even if no points were earned. Reconnect: Follow every instruction in order, including set. Replace the number even when no points were earned.

P5 / Card 5. A mistake to check: A new game starts without initialization and inherits an earlier game's score. Better idea: Give each new game its stated starting value before processing events. Reconnect: Show the end of one game and the starting value of a new game on separate cards. Initialize the new game.

P6 / Card 1. A mistake to check: The switch creates the energy that lights the lamp. Better idea: The battery supplies energy. Closing the switch completes a conducting path; the switch does not create energy. Reconnect: Sketch the battery, lamp and conducting return path. Open and close the switch on the sketch.

P6 / Card 2. A mistake to check: One successful test proves the switch always works. Better idea: Record every trial, including failures. Five trials support a limited comparison, not a guarantee. Reconnect: Read every actual or explicitly supplied trial from the accepted Engineering activity. Include failures and identify the source.

P6 / Card 3. A mistake to check: Changing several components establishes which single change caused an outcome. Better idea: Change one contact feature while keeping battery, bulb, wires and procedure fixed. Reconnect: Name one contact feature to change. Keep battery, lamp, wires and procedure fixed.

P6 / Card 4. A mistake to check: The taller closed-switch bar proves the best design without checking open-switch control. Better idea: Use both closed-light and open-dark observations, and acknowledge the limits of the tests. Reconnect: Read both closed-light bars, then inspect both open-dark counts. Both criteria matter.
